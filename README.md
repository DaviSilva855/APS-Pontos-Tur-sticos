## APS - Pontos Turísticos de São José dos Campos

-Sobre o projeto<br>
    Este projeto foi desenvolvido como parte de uma Atividade Prática Supervisionada (APS) e tem como objetivo apresentar          alguns dos principais pontos turísticos e comerciais da cidade de São José dos Campos - SP.<br><br>
    O site foi desenvolvido utilizando tecnologias da web e busca fornecer informações sobre locais de interesse da cidade de      forma organizada e intuitiva.

## Tecnologias Utilizadas

-HTML5

-CSS3

-Bootstrap
